# 🧵 Apna Darzi – Tailoring Service Android Application

A modern Android application that connects customers with professional tailors through a simple, user-friendly platform. **Apna Darzi** streamlines the process of browsing tailoring services, managing user profiles, communicating with tailors, and exploring personalized clothing solutions.

---

# 📖 Project Overview

**Apna Darzi** is an Android application developed using **Kotlin** and **Android Studio**. The application provides an intuitive platform where users can discover tailoring services, manage their accounts, communicate through chat, and browse clothing-related offerings.

The project follows a structured architecture with dedicated activities, fragments, view models, and repository classes to ensure scalability and maintainability.
